# Mini Airport — 設計書 v0.2（ドラフト）

目的：空港を大きくし、**館内の部屋ごとの動き**（チェックイン、保安検査、搭乗、手荷物受取、手荷物探し…）を見られるようにする。
方針：**作る前に、部屋・モノ・人の流れをこの文書で確定させる**。実装は「パーツ → 部屋キット → 空港へ統合」の順に進める。

---

## 0. 現状（v0、動いているもの）

- 屋外：滑走路1本、誘導路、スポット3つ（A1〜A3）、ボーディングブリッジ、GSE車両置き場、ターミナル（外観だけ）、管制塔、格納庫、道路、駐車場
- 動き：着陸 → スポットイン → 給油・手荷物・ブリッジ → プッシュバック → 離陸、をループ（25分ぶん早回しで詰まりなし）
- 地上車両：一方通行の構内道路を走り、前に何かあれば止まる。滑走路は同時に1機しか使えない
- 館内：**まだ何もない**（ガラスの箱だけ）

## 1. 大方針（2026-10-27 決定）

| # | 論点 | 決定 |
|---|---|---|
| A | 館内の見せ方 | **断面表示（ドールハウス）**：ズームすると屋根が消え、壁は腰の高さで切れて見える |
| B | 階数 | **2階建て：出発2F／到着1F**。断面表示は「2Fを見る ⇄ 2Fを外して1Fを見る」の切り替え式 |

| D | 人と荷物の一貫性 | **便ごとに実体で追跡**：預けた荷物がその機体に積まれ、到着便の荷物がターンテーブルに出てくる |

### 2階建てにしたことで決まること
- **ボーディングブリッジは2Fにつながる**（床の高さ 3.0）。到着客も2Fで降りる
- 到着客は2Fの専用通路（出発客とは分けた、ガラス壁の通路）を歩き、**エスカレーターで1Fへ降りて**手荷物受取へ行く
- 陸側の道路も2層にする：**2Fの高架の出発車寄せ**（ランプで上がる）と、**1Fの到着車寄せ**（タクシー・バス乗り場）。ジオラマの見どころにもなる
- 1Fには手荷物仕分け場（BHS）も入る。チェックインで預けた荷物は2Fから**シュートで1Fへ下りる**
- 階の高さ：各階 3.0（天井高 2.6 ＋ 床スラブ 0.4）、屋根を含めた建物の高さは約 7

## 2. スケールのルール

- **人の縮尺**：キャラクター＝高さ 1.3（実寸 1.7m 相当）、**1 unit ≈ 1.3m**
- **館内と建物はこの人の縮尺で作る**：カウンター高さ 0.8、天井高 2.6、扉幅 1.0
- 飛行機と滑走路だけは「おもちゃ縮尺」に縮めて許容（旅客機は全長14で実寸の約0.4倍）。ジオラマとしての見栄えを優先する
- 色はパーツカタログのパレット（white/cream/navy/ink/orange/yellow/teal/sky）だけを使う。**部屋ごとに差し色を1色**決める（下表）

**人の動きの仕組み（`routine()`、`src/interior.js`）**
- 台本＝「場所まで歩く → そこでポーズを取って○秒待つ」を並べたもの。最後まで行くと最初に戻る
- 行き先はその場で決めることもできる（例：列の出口で、いちばん空いているカウンターを選ぶ）
- 同じ部屋の人どうしは、**すぐ前に人がいれば止まる**ので自然に列ができる。4秒詰まったらすり抜けて、絶対に固まらないようにしてある
- 台本の中で荷物を出し入れできる：チェックインで預けるとスーツケースが消え、受取で持ち上げると現れる
- 新しいポーズ：入力・座る・持つ・持ち上げる・両手を上げる
- 新しい職員：保安検査員（スカイのベスト）、ゲート係（ティール）、仕分け作業員（オレンジのベスト）、カフェ店員（茶色のエプロン）、手荷物サービス係（赤のスカーフ）

**本番に向けた課題**：部屋キットの台本は部屋の中だけで完結している。空港に組み込むときは、部屋をまたいで1人の乗客を追跡する（§5の流れ）ように、台本を「便と乗客のシミュレーション」から作る形に置き換える。

## 5. 流れ（シミュレーションの定義）

**出発客**：2Fの高架車寄せで降りる → R1で並ぶ → カウンター（約8秒）→ 荷物はR5へ → R2で列 → 検査（約6秒、5%で再検査）→ R3で過ごす → 搭乗開始でR4に並ぶ → 改札 → ブリッジ → 機内

**預け荷物**：R1のベルト → R5で仕分け → その便のカート → トラクターでスポットへ → 貨物室

**到着客**：機体 → ブリッジ（2F）→ R6の専用通路 → エスカレーターで1F → R7で自分の荷物を待つ（荷物は機体 → カート → R7のシュート → ターンテーブル）→ 受け取る → R9 → 車寄せ／バス。**3%の確率で荷物が出てこず、R8へ行く**

便ごとの人数：1便あたり見える乗客は **12〜18人**（性能と見栄えのバランス）。

## 5.5 ストーリー（「今日の主役たち」）

**物語の仕組み**
- 物語＝「きっかけ（条件）→ 行動 → ログの一文」を並べた台本。例：`荷物が出ない → R8へ歩く → 「ソラの荷物は次の便で届くそうです」`
- 台本は JSON に書いて、あとから話を追加しやすくする
- 一日の流れ：午後に始まり → 夕方 → 夜の最終便が出たら、翌朝に戻ってまた一日が始まる（時間帯ボタンとは別に「自動で一日を進める」モードを用意）
- 小さな出来事（ランダム、低確率）：子どもが迷子になって案内所へ／カフェでコーヒーをこぼす／鳩がエプロンに降りる／雨が降り出して傘が開く

## 6. 見せ方（カメラと表示）

- 引いて見るとき：今の外観のまま
- ズームしてターミナルに近づくと、屋根が半透明 → 消える。壁は腰の高さで切る（断面表示）
- **階の切り替え**：「2F 出発 / 1F 到着」ボタン。1F表示のときは2Fの床と中身をフェードアウトさせ、2Fの柱だけ細く残して位置関係がわかるようにする
- エスカレーターと荷物シュートは、2Fと1Fの両方の表示で見えるようにする（階をまたぐ動きを追えるように）
- パネルに「部屋」タブを追加：部屋を押すとカメラがその部屋へ寄り、待ち人数・平均待ち時間・処理中の数を表示
- 人をクリックすると、その人を追跡して「いま何をしているか」を表示（例：「保安検査待ち・5分」）

## 7. 作る順番

1. この設計書の確定（大方針A〜D、部屋の並び、モノの寸法）
2. **パーツカタログに「館内パーツ」を追加**し、モノを1つずつ見た目で確定させる
3. **部屋キット**：部屋ごとに単体のページで、部屋と人の動きを作り込む（R1 → R2 → R4 → R7 → R5 → 残り）
4. 空港を拡張（スポット6、ターミナル大型化）し、部屋キットを配置して乗客と荷物をつなぐ
5. ストーリー（主役の台本、パネル、追跡カメラ）
6. 夜景・UI・性能調整（人が増えるので、建物や人のメッシュをインスタンス化・結合）

## 7.5 実装状況 v2（2026-10-27）

**空港の拡張（`layout.js` / `scenery.js` / `terminal.js`）**
- スポット6（A1〜A6）、滑走路204、ジオラマ 220×109
- ターミナル 122×29、2階建て。北から順に：到着専用通路（2F）／ゲート6室（2F）／**出発コンコース（2F、設計中に追加）**／チェックイン・保安検査・ラウンジ（2F）＋吹き抜けの下に手荷物受取・到着ロビー（1F）。手荷物仕分け場は1Fのチェックインの下
- 高架の出発車寄せ（2F）と東西のスロープ、1Fの到着迎車レーン、管制塔・GSE置き場は東へ移動
- 表示：自動（近づくと屋根が開く）／外観／2F 出発／1F 到着。1Fのときは2Fの床・部屋・壁を外し、1Fの壁を腰の高さで切る
- 性能：止まっている部品を材質ごとに結合（人は約45→16メッシュ、飛行機は約150→36メッシュ）。館内を表示した状態で描画呼び出しは約7,800回、狭いペインで約43fps

**便ごとの乗客（`pax.js`）**
- 出発客：高架の車寄せで降車 → チェックイン（空いている席を選び、スーツケースを預ける）→ 保安検査 → ラウンジで待機 → 自分のゲートに便が来たらコンコースを通ってゲートへ → 座って待つ → 搭乗開始で列 → 改札 → ブリッジ → 機内。**搭乗した人数を便ごとに数える**
- 到着客：駐機してブリッジがつながると、機体から1人ずつ降りる → 到着通路 → エスカレーター → 1F → 手荷物受取（空いている場所で待ち、持ち上げるとスーツケースが現れる）→ 迎車レーン。6%は荷物が出てこず、手荷物サービスへ寄る
- 飛行機は、搭乗中の人がいる間はブリッジを外さない（最大15秒延長）
- 確認：早回し8分で、搭乗23人・降機56人。人が永久に止まることはない（すぐ前の人が止まっている＝列の場合は並んで待ち、動けない相手なら4秒ですり抜ける）

**預け荷物の追跡（`bags.js`）✅**
- 出発：計量台 → カウンター裏のベルト（2F）→ 床下へ → 仕分け場（1F）の本線 → 押し出しアーム → スポットごとのシュート（A＝奇数番、B＝偶数番のスポット）に溜まる → そのスポットの手荷物トレインが機体へ向かうときにカートへ積む → 機体の貨物扉へ1個ずつ移す（便ごとに数える）
- 到着：降りた乗客1人につき荷物1個が貨物室にある → トレインが機体に着くと、積み込みのあとにカートへ降ろす → トレインが車庫に戻ると、受取場の投入口からターンテーブルへ → **持ち主が自分の荷物を目の前で見つけたときだけ持ち上げる**（他人の荷物は取らない）。6%の乗客は荷物が便に乗っておらず、しばらく待ってから手荷物サービスへ。240秒誰も取らない荷物は遺失物として下げる
- 手荷物トレインのカートは空で出発し、実際に追跡している荷物だけが載る
- 確認：早回し8分で、預け入れ69個、機体へ積み込み22個、取り降ろし50個、持ち主が受け取ったもの37個
- 簡略化している点：仕分け場のシュートからカートへの積み替えは、トレインが車庫を出る瞬間に行われる（シュートと車庫が離れているため）

**表示言語の切り替え（`i18n.js`）✅**：パネル右上のボタンで日本語 ⇄ 英語。パネル・ラベル・便の状態・都市名・ログが切り替わり、選んだ言語はブラウザに保存される。3Dの案内サインは最初から日英併記

**ストーリー（`story.js`）✅**
- 主役はふつうの乗客・乗務員と同じ仕組み（便・荷物・列）の上で動き、台本の要所（チェックイン、X線、ゲート、搭乗、荷物待ち…）に着くとセリフ（日英）が出る。物語が終わると、しばらくして新しい便で最初からまた始まる
- ハナの家族（3人）：同じレーン・同じ席の並びで一緒に行動する。X線でクマのぬいぐるみが止められ（6秒長く待つ）、搭乗の時点でその便の行き先が那覇になる
- ケンジさん：着陸してくる便に合わせて登場。走る（速さ約2倍）。チェックインと保安検査は優先（列をとばす）、ラウンジに寄らない。**飛行機は彼が乗るまでブリッジを外さずに待つ**（最大80秒）
- ソラ：到着便の出発地が台北になる。荷物が便に乗っておらず → 手荷物サービス → 次の便が着いてから「荷物が届いた」→ 街へ
- ミドリさん：荷物を受け取ったあと到着ロビーへ回り、「ミドリさん」のボードを持つ人の前で再会 → 車へ
- タナカ機長と客室乗務員：駐機した便に合わせて、コンコースからゲートへ。打ち合わせのあと乗客より先に乗り込む
- マーシャラーのユウ：A3 に常駐し、飛行機が入ってくると誘導・停止のセリフ
- 確認：早回し15分で全員の物語が最後まで進んだ（ケンジさんは間に合い、ハナの一家と機長は同じ便で出発、ソラは次の便で荷物を受け取り、ミドリさんは再会）

**パネルと追跡 ✅**
- 「ストーリー」欄：主役ごとに最新の出来事と「見る」ボタン。ログにも★付きで物語のセリフが混ざる
- 主役の頭上に名前の札（★ ハナ など）
- 人をクリック（または「見る」）すると、カメラがその人に寄って追いかける。ターミナル内にいれば、その人がいる階（2F／1F）に表示が自動で切り替わる。カードには「今していること」・ゲート・便が出る

**まだのこと（次の候補）**
- 出発客の生成ペースと便の数のバランス（ラウンジに人が溜まりやすい）
- 1F北側（ゲートの下）の何もない空間の作り込み、R9到着ロビーへの動線（いまは受取から直接外へ出る）
