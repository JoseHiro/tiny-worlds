# 機内の世界（In-flight cabin）— 設計書 v0.1

目的：フライトページ（`world/flight.html`）で、**外の景色 ⇄ 機内** を切り替えられるようにする。機内では、離陸から着陸までの時間に合わせて、客室の暮らし（ベルトサイン、飲み物、食事、映画、眠る人、トイレの列、着陸準備）が進む。
方針：いつもどおり **設計 → パーツ（カタログ）→ 機内キット（単体）→ フライトに組み込み** の順に進める。

## 2. スケール（空港と共通）

- 人＝高さ 1.3（1 unit ≈ 1.3m）。座面 0.3、天井高 2.3（断面で切るので見えるのは 1.75 まで）
- エコノミーの座席幅 0.5、ピッチ 0.85 は空港の機内ビュー（`airport/src/cabin.js`）と同じ
- 客室の内幅 6.2：エコノミー 3-3-3 ＝ 席 0.5×9 ＋ 通路 0.7×2 ＋ 壁ぎわ 0.15×2
- 胴体の半径 3.4、客室の長さ約 44（機首 +X、床 y = 0、左側＝ −Z、L1 ドアは −Z）

## 4. 機内の時間割（フライトの t と連動）

フライトは今 46 秒（`T = 46`）。機内を見ている間も同じ時計で進む。秒は flight.js の t。

| t | 外 | 機内 |
|---|---|---|
| 0–9 | 離陸・上昇 | ベルトサイン点灯、照明を落とす、全員着席、乗務員は補助席 |
| 9–14 | 雲の上へ | ポーンと音でベルトサイン消灯。立つ人、棚を開ける人、トイレへ向かう人 |
| 14–22 | 巡航 | 飲み物カートが通路2本を前から進む（ビジネスはトレーで手渡し） |
| 22–30 | 巡航 | ミールサービス：テーブルを出す、トレーが配られる、食べる |
| 30–38 | 巡航・夜の色 | 照明が紺に。眠る人、映画を見る人、トイレの列、窓の日よけが下りる |
| 38–40 | 揺れ | ベルトサインが一度点く。カートを止める |
| 40–46 | 降下・着陸 | 日よけを上げる、テーブルとリクライニングを戻す、乗務員が通路を確認、補助席へ |

- 46 秒は機内には短い。**機内を見ている間は時間をゆっくり（×0.5）にする**案を、組み込みのときに決める（§7 未決）
- 那覇便ではハナの一家（エコノミー 31A・31B・31C、窓側がハナ、クマを抱えて外を見る）を追いかけられる

## 6. メモリ（必ず守る）

- **座席は InstancedMesh**：エコノミー 126 席分の座席は「部品ごと 1 つの InstancedMesh」。リクライニングとテーブルは行列で動かす
- **背景の乗客もインスタンス**：体・頭・髪をそれぞれ 1 つ。ポーズ（起きている／寝ている）は行列の傾きで表す
- 動く人（追いかける人、乗務員、通路を歩く人）だけ person() を使う。10〜20 人まで
- 画面のテクスチャは **1 枚のキャンバスを全座席で共有**（地図と映画の 2 枚だけ）
- ジオメトリとマテリアルは `mat()` のキャッシュと共有ジオメトリで。カタログでも本番でも **レンダラーは 1 つ**
- 機内は**初めて切り替えたときに作り**、あとは使い回す（作り直さない）。フライトの終わりにページごと遷移するので dispose は不要

## 7. 組み込みで決めたこと（2026-10-31）

- 時間の速さ：**×1 のまま**（外と機内は同じ時計。46 秒のあいだに §4 がひと通り進む。ゆっくり見たいときは `cabin.html` の ×½）
- 切替：**ボタン（外／機内）と C キー**。自動のカット切替はしない。機内ではカメラ6つ（全体・ビジネス・ギャレー・ハナの席・後方・操縦室）、ドラッグで回せる
- 帰りの便（那覇 → 羽田）も同じ客室。座席の画面の地図は逆向きに進む。機体の色（尾翼・エンジン・帯）は便のリバリーに合わせる
