# Tiny Worlds — 世界地図と空の旅（設計 v0.1）

目的：ばらばらに作ってきた世界（空港・那覇・古都・カフェ）を、**飛行機で行き来できる一つの世界**にする。
最初の一本は **ミニ空港 → 那覇**。ハナの一家の旅（空港 → 道 → 海 → 道 → 空港）で、いま唯一欠けている「飛んでいるところ」を埋める。

進め方はこれまでと同じ：**設計 → パーツ → 場面 → 世界に組み込み → つなぐ**。

---

## 0. いまのつながり（2026-10-30 時点）

```
 airport/            ── ハナの一家が那覇行きに搭乗 ──→  （ここが無い：飛行）
 road/?leg=out       那覇空港の到着口 → レンタカー → 海の駐車場 → naha/?from=road
 naha/               海の一日 → お土産 → road/?leg=back
 road/?leg=back      車を返す → 那覇空港 → 「空港の世界へ（ハナの帰りの便）」→ airport/
```

- 空港の行き先リスト（`airport/src/sim.js` の CITIES）：札幌・仙台・大阪・福岡・**那覇**・広島・ソウル・台北・上海・香港
- 世界として存在する町：**那覇**（road + naha）、**古都**（京都・鎌倉ふう、架空）、**北欧のカフェ** Stilla Kaffe、**和のカフェ** 喫茶あめつち、**バルセロナ**のテラスとサグラダ・ファミリア

## 1. 決めること（推奨つき）

**決定（2026-10-30）**：A ③地球儀から東アジアへズーム／B ①東京あたり／C ②巡航と降下を別ページ／**D ① road の西に滑走路を足して、着陸は road の世界で見せる**。E・F は推奨どおり（E②、F②から）。


| # | 論点 | 選択肢 | 推奨 |
|---|---|---|---|
| A | 地図の形 | ①ローポリの**地球儀**（回せる。ヨーロッパも入る） ②東アジアだけの平らな絵地図 ③地球儀から東アジアへズーム | **③**。最初は地球儀で全体を見せ、日本のあたりへ寄ると路線と飛行機がはっきり見える。バルセロナ・北欧は地球儀の裏側にある |
| B | ミニ空港がある町 | ①東京（羽田ふう、HND） ②架空の町 ③決めない | **①東京あたり**。行き先リストが国内線＋近いアジアなので自然。名前は「Mini Airport」のまま、地図上の位置だけ東京 |
| C | 空の旅の見せ方 | ①空港の場面から離陸 → 巡航 → 那覇に着陸まで1本の場面 ②**巡航と着陸の場面**を別ページで作り、空港で離陸を見届けたあとにそこへ飛ぶ ③地図上で飛行機の点が動くだけ | **②**。離陸はもう空港の世界にある。新しく作るのは雲の上の巡航（島や海が流れる）と那覇への着陸。約60秒、スキップできる |
| D | 那覇空港の着陸側 | ①road の西のはしに滑走路を足す ②**空の旅のページの最後に小さな那覇空港**（滑走路・小さなターミナル・ヤシ）を作り、着いたら road/?leg=out へ | **②**。road はすでに「到着口から」始まるので、着陸してターミナルに入ったところでつなぐ。空港のパーツを使い回すので軽い |
| E | 地図に出す路線 | ①世界がある町だけ ②行き先リストの全部の町、**世界がある町は目立たせる** | **②**。にぎやかに飛んでいて、行ける町は光る。まだ世界が無い町は「準備中」 |
| F | 地図の飛行機と空港の世界 | ①空港の世界の便と**同じ時計・同じ便名**で動く ②地図は地図で自分の時刻表 | **②で始め、あとで①**。最初は同じ CITIES と便名の付け方を共有するだけにする |

## 2. 世界地図（`world/index.html`）

### 2.1 見た目
- 地球：低い分割の球（面が見えるローポリ）。海はパステルの水色、陸はクリーム〜若草。国境線は描かない
- 陸の形：世界地図のデータ（world-atlas の 110m、CDN から読み込み）をキャンバスに描いて球に貼る。テクスチャは1枚（2048×1024）
- 雲：小さなローポリの雲をいくつか（InstancedMesh 1つ）、ゆっくり流れる
- 背景：空港の空と同じクリーム色、地球のふちに淡い大気のにじみ

### 2.2 町のピン
世界がある町は、その世界を表す**小さな模型**を地球の上に立てる。

| 町 | 模型 | 開く |
|---|---|---|
| 東京（ミニ空港） | 管制塔 | airport/ |
| 那覇 | ヤシとシーサー | road/ → naha/ |
| 京都（古都） | 五重塔 | koto/ |
| バルセロナ | サグラダ・ファミリアのシルエット | cafe/barcelona.html |
| ストックホルム（北欧のカフェ） | 赤い木の家 | cafe/nordic.html |

- 世界がまだ無い町（札幌・ソウル・台北など）は小さな白い点と町の名前だけ
- ピンにマウスを乗せると名前（日本語/English）、クリックで寄ってカードを出す：「開く」「ここへ飛ぶ」
- 和のカフェ（喫茶あめつち）は京都のカードの中に入れる

### 2.3 飛行機と路線
- 東京から各町へ**弧の路線**（大圏の弧を少し持ち上げた線）、点線でうすく
- 飛行機：空港の `airplane()` を小さくしたものが路線の上を飛ぶ。同時に6〜8機。機体は3つの塗装を共有
- 飛行機をクリックすると便名・行き先が出る。那覇行きなら「この便に乗る →」で空の旅へ

### 2.4 操作
- ドラッグで回す、ホイールで寄る（寄りすぎると日本の上で止まる）
- 右上に 日本語/English、左下に「Tiny Worlds」へ戻る

## 3. 空の旅（`world/flight.html?from=HND&to=OKA`）

約60秒の場面。どこでもスキップできる（「着陸まで飛ばす」）。

| 時間 | 場面 | 中身 |
|---|---|---|
| 0–8秒 | 上昇 | ミニ空港を後ろに、雲を抜ける（空港は遠景の模型として簡単に） |
| 8–40秒 | 巡航 | 雲の上。下に海と島が流れる（九州・奄美のような島影）。右下に小さな地図で現在地 |
| 40–50秒 | 降下 | 雲の下へ。サンゴ礁の浅い海の色、那覇の島影が近づく → 「着陸へ」で road/?leg=out に切り替わる |

- カメラ：飛行機の斜め後ろからの追跡を基本に、窓からの眺め（客室の窓枠ごしの雲）を1カット入れる
- 便名と行き先：URL で受け取る（空港の便から来たときはその便名）。ハナの一家の便なら「ハナの一家も乗っています」
- 帰り（`?from=OKA&to=HND`）：同じ場面を逆に、最後はミニ空港に着陸 → airport/ へ

### 3.1 那覇空港の滑走路（road の西のはし、D①）
- いまの road は「那覇空港」のターミナル正面（東側、x ≈ −20）から始まる。その**裏（西側）を空港の裏手**にする
- ターミナルの西に駐機場（スポット1つ、ボーディングブリッジ1本）、その西に**南北の滑走路1本**（x ≈ −100、長さ約 200）と誘導路、小さな管制塔
- road/?leg=out の最初に**着陸の場面**を足す：北から降りてくる → 接地 → 減速 → 誘導路 → スポットに入る → ブリッジがつく → いまの「到着口からハナの一家が出てくる」へ続く
- 機体は空港の `airplane()` をそのまま使う（同じ縮尺）。便名は URL（`?flight=MA 237`）で受け取る
- 帰り（leg=back の最後）：ターミナルに入ったあと、同じスポットから押し出し → 離陸、は**あとで**。まずはリンクで空の旅へ

## 4. つなぎ方

| どこから | どうやって | どこへ |
|---|---|---|
| 空港の世界 | 那覇行きが離陸したあと「この便で那覇へ →」 | world/flight.html（その便名） |
| 空港の世界 | ハナの一家が搭乗したとき（物語） | 同上 |
| 世界地図 | 那覇行きの飛行機、または那覇のカード「ここへ飛ぶ」 | 同上 |
| 空の旅 | 降下の終わり | road/?leg=out（着陸の場面から） |
| road の帰り | 「空港の世界へ」を「帰りの便に乗る →」に変える | world/flight.html?from=OKA&to=HND → airport/ |
| Tiny Worlds の目次 | いちばん上に「世界地図」 | world/ |

## 5. 縮尺・メモリ

- 地図：地球の半径 100。飛行機は長さ 1.5 くらいに縮めて見せる
- 空の旅：空港と同じ縮尺（飛行機の長さ約 13）。海は大きな平面1枚＋色のグラデーション、島は低いポリゴンの塊を数個
- 共有：材質は空港の `mat()` を使う。雲・木は InstancedMesh。テクスチャは地球の1枚と小さな地図の1枚だけ
- ページごとに WebGLRenderer は1つ

## 6. 作る順番

1. 世界地図：地球・陸のテクスチャ・町のピン・カード（開く）
2. 地図の路線と飛んでいる飛行機
3. 空の旅：上昇・巡航（雲・海・島）・降下
3.5 road の西に那覇空港の滑走路と駐機場、leg=out の最初に着陸
4. つなぐ：空港 → 空の旅 → road、road の帰り → 空の旅 → 空港、目次に世界地図
5. あとで：新しい町（札幌・ソウルなど）の世界、地図と空港の便を同じ時計で動かす（F①）

## 7. 実装メモ（2026-10-30）

- **世界地図** ✅ `world/index.html` + `src/map.js`、町と世界のデータは `src/places.js`
  - 地球は SphereGeometry（flatShading）に陸のテクスチャ1枚（world-atlas 110m を CDN から読み、キャンバス 2048×1024 に描く。180度線をまたぐ陸は経度をつなげて、はみ出した分を1周ずらして描き直す）
  - 寄ると北へ少し傾けて見る（`tilt()`）。「地球」「東アジア」「ヨーロッパ」の3つの視点、最初は地球全体 → 東アジアへ
  - 飛行機は塗装ごとに1機作って clone（ジオメトリを共有）。雲は InstancedMesh 1つ
  - 町・飛行機のクリックは画面上の近さで拾う（レイキャストしない）。那覇のカードと那覇発着の便に「飛ぶ」ボタン
- **空の旅** ✅ `world/flight.html` + `src/flight.js`（?from&to&flight&story&stay）
  - 飛行機は原点に止まり、`world` グループが西へ流れる。雲は 460 個を折り返して使う。46 秒、6カット（窓の席のカットは CSS の窓枠を重ねる）
  - 着く側の町は左右反転して、海から進入する
  - 終わると road/?leg=out（那覇）か airport/（ミニ空港）へ自動で移る
- **那覇空港の滑走路** ✅ `road/src/main.js`（ターミナルの西：滑走路 x = −125、駐機場、ボーディングブリッジ、管制塔、西の海）
  - leg=out の最初に着陸（`story.js` の `outLand` → `outTaxi` → ブリッジ → `outArrive`）。leg=back の最後は「帰りの便に乗る」→ 空の旅（OKA → HND）
- **つなぎ** ✅ 空港のパネル（ハナの旅の続き・世界地図）、那覇行きの便のカードに「この便で那覇へ飛ぶ」、目次のいちばん上に世界地図
