# 運河の町 Venice — 設計 v0.1（2026-11-12）

目的：**ヴェネツィアのような運河の町**を、**正方形の台にのった1区画の町**として、手のひらサイズのジオラマにする。大運河がS字に流れ、色とりどりの館が水から立ち上がり、ゴンドラと水上バスが行き交う。
方針：デザインを細かく洗い出してから作る（ユーザーの要望）。形は Tiny Worlds の決まりどおり、**丸く、ずんぐり、おもちゃのように**。
雪まつりで分かったことを最初から入れる：**動画は遠目から**（盤面ごと見える引きの画角がいちばん好評）、**アクティビティを多く**、**冒頭は地球儀からの飛行機**（`film/flyin.js`）、**表紙は `film/COVER.md` の決まり**。
進め方：**設計（この文書）→ 部品と素材の見本帳（`venice/parts.html`）→ 確認 → 町に組み立て（`venice/index.html`）→ 仕上げ・動画・トップページ・地球儀の模型**。

## 1. ヴェネツィアの分解（見えるものすべて）

### 1.1 町の形（正方形の1区画）
- 陸は**小さな島の集まり**。道の代わりに運河、運河の上に橋。車は1台もない
- **大運河**：幅 4。北西の角から入り、S字に曲がって南東のラグーンへ抜ける
- **細い運河**：幅 1.2〜1.6。大運河から枝分かれして、ブロックの間を縫う。3〜4本
- **ラグーン**：南東の角。広い水面、**船着き場**（水上バスの停留所）、**縞の杭**の並ぶ岸
- **大広場**：ラグーンに面した、台でいちばん広い石の広場。鐘楼、ドームの聖堂、回廊（アーケード）
- **小広場（カンポ）**：町の中に2つ。井戸、木、カフェの椅子
- **路地**：館の間の細い石の道。幅 0.6〜1。曲がりくねって、橋で運河を越える
- 台の縁：**水の断面**（翡翠色の層と、下に沈む杭）と、石の岸の断面

### 1.2 空と光
- **晴れた午後**：高い所は澄んだ青、地平線へ淡い桃色がかった白
- 太陽は南西から、やや低め。館の正面に**暖かい光**、運河の向こう岸に**長い影**
- **水面のきらめき**：日の当たる水に細かい光の点が揺れる
- **水に映る館の色**：館の色が水面に揺れて伸びる（色の帯で軽く作る、§6）
- 遠くに**かすむ島影**（台の外、背景の板）

### 1.3 水
| 水 | 見え方 |
|---|---|
| 大運河 | 明るい翡翠色（`#3fa79a`→`#2c8a86`）、少し濁って底は見えない。小さな波、船の**引き波**が岸へ広がる |
| 細い運河 | 大運河より暗い緑、静か。館の影が落ちる。**館の色が映る** |
| ラグーン | 青みが強い（`#3a9bc0`）、広く明るい。遠くへ向かって淡く |
| 岸ぎわ | 石の壁に**藻の緑の帯**（満ち引きの跡）、水の線にあわい泡 |
| 船の跡 | 白い引き波（V字）、ゴンドラの櫂のまわりの小さな渦 |

### 1.4 館（町のほとんど）
ヴェネツィアの家は**水から直接立ち上がる**。1階に**水の玄関**（舟を着ける扉と石段）。

| 部分 | 見えるもの |
|---|---|
| 壁の色 | 黄土、テラコッタ、サーモンピンク、くすんだ赤、クリーム、淡い緑。**同じ色を隣に並べない** |
| 壁の質感 | 漆喰がところどころはげて**れんがが見える**、下のほうに水の跡 |
| 窓 | **尖ったアーチの窓**（ゴシック風、上が三つ葉のような形）、緑の**よろい戸**、白い石の縁 |
| 窓の並び | 正面のまん中に**3〜5連のアーチ窓**（大広間の窓）、両脇に1つずつ |
| バルコニー | 白い石の小さなバルコニー、手すりの柱 |
| 屋根 | 低い**テラコッタ瓦**、屋根の上に**木のテラス（アルターナ）** |
| 煙突 | **じょうごの形の煙突**（上が広がる）。ヴェネツィアらしさの決め手 |
| 花 | 窓辺の**花箱**（赤いゼラニウム）、壁をはうつた |

館の型（大きさと飾りを変えて使い回す）：
1. **大きな館（パラッツォ）**：4階、正面に5連アーチ窓が2段、大運河に面する
2. **中くらいの館**：3階、3連アーチ窓、バルコニー

4. **角の家**：路地と運河の角、下が店
5. **低い倉庫**：2階、大きな水の扉、荷を上げる滑車

## 3. 可愛くする決まり

1. **角を全部丸くする**：館も橋も丸い角（`IKit` と `rounded()`）。アーチ窓はぷっくり
2. **ずんぐりさせる**：人は **2.5 頭身**（背 0.58）。館は本物より**低く太く**（4階でも人の 6 倍くらい）
3. **遠近をうそにする**：鐘楼は人の 25 倍、聖堂は 12 倍、大きな館は 7 倍。運河は本物より**広め**（舟がよく見えるように）
4. **色を減らして揃える**：壁は暖かい土の色（黄土、テラコッタ、サーモン、クリーム）、水は翡翠、空は青、差し色は**よろい戸の緑**と**杭の縞**と**船頭のシャツの赤**。黒は使わず紺
5. **窓は大きめに**：アーチ窓をはっきり大きくして、遠目でもヴェネツィアだと分かるように
6. **じょうご煙突を必ず**：屋根の上の煙突はヴェネツィアの決め手。どの館にも1〜3本
7. **台にのせる**：正方形の角丸の台。縁で水の層と沈んだ杭が見える

## 6. 作り方

- **ページ**：`venice/index.html`（町）、`venice/parts.html`（見本帳）、部品は `venice/src/`。舞台は `room/src/stage.js`、合体は雪まつりの `snowfest/src/kit.js` の **`IKit`** と `rounded()`（共通の場所へ出して使う）、人は雪まつりの `winter()` の夏服版
- **館の作り方**：館は「箱＋正面の飾り」。正面のアーチ窓・よろい戸・バルコニーは**インスタンス**（窓の数が多いので）。壁の色は頂点色。1つの材質に「色のむら」「はげた所のれんが」「水の線の藻」を入れる
- **水の作り方**：Blue domes の `sea.js` を元に、運河の形（マスク画像）で水面を1枚にする。映り込みは本物の反射ではなく、**岸の館の色を帯にして揺らす**（軽い）。きらめきは日の向きで出す
- **舟の動き**：運河の中心線を曲線で持ち、舟はその上を進む（雪まつりの `lanes` と同じ仕組み）。ゴンドラは角でゆっくり曲がる
- **鳩**：インスタンス 1 つ。地面を歩く状態と、飛び立って円を描く状態
- **メモリ**：動かないものは材質ごとに1つのメッシュ（壁、白い石、瓦、ガラス・発光）。窓・杭・鳩・人の一部はインスタンス。影は 2048 を1枚。描くのは1つのレンダラーだけ
- **灯り**：午後の太陽（南西から、暖かい白）と、空の青の半球光。水のきらめきと金の飾りに弱いブルーム

## 7. 動画の設計（最初から決めておく）

- **冒頭（0〜4秒）**：`film/flyin.js` で、地球儀のミニ空港からヴェネツィア（VCE）へ。ヨーロッパまで遠いので、**地球儀が回って日本からヨーロッパへ**弧を描いて飛ぶ形にする（札幌より長い旅になる）。模型に飛び込んで白くなり、町の全景へ
- **ショットはすべて遠目から**（雪まつりで分かったこと）：盤面の半分以上が入る高さから、アクティビティが見える位置へ
- ショットの案：①全景に降りる ②大運河のS字とゴンドラの列 ③大きな石の橋と人だかり ④大広場の鳩が一斉に飛ぶ ⑤水上バスの乗り降り ⑥カフェの楽団 ⑦水上タクシーの疾走 ⑧ゴンドラ乗り場 ⑨引いて全景、名前のカード
- **見どころの瞬間**：鳩が一斉に飛び立つ瞬間を、ショット④の途中に合わせる（雪まつりのビッグエアと同じ合わせ方）
- **表紙**：全景の引きの画角、上の 1/3 に空が来るように。`film/COVER.md` の決まりで「Venice」
- **音**：水の音（小さな波）、遠くの鐘、鳩の羽音、アコーディオンの短い節（作り物）
