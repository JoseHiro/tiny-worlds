# World 06 — エンジニアの部屋（設計 v0.1・ドラフト・2026-11-04）

> 夜、ひとり暮らしの部屋。モニターの青い光とデスクライトの電球色、湯気の立つマグ。コーヒーを淹れて、コードを書いて、ときどき伸びをする。見ているだけで落ち着く、**cozy なエンジニアの部屋**の断面ジオラマ。

方針：いつもどおり **設計（この文書）→ パーツ（カタログ）→ 部屋に並べる → 人の動き** の順。縮尺はカフェ・バンコクと同じ（**1 m ≒ 0.76、人 1.3**）。

## 1. 調べたこと：「エンジニアっぽい部屋」とは

デスク環境の写真（r/battlestations、r/desksetup、「デスクツアー」系の投稿や動画）でよく見るものを集めた。

### 1.1 机の上（主役）
- **モニター2枚**（横長のウルトラワイド1枚＋縦置き1枚、または27インチ2枚）。**モニターアーム**で浮かせ、机の上を空ける
- **ノートPC**（ステッカーだらけ）を**スタンド**に載せ、閉じてつなぐか、3枚目の画面にする
- **自作キーボード**：分割型やキーキャップの色違い、カールしたケーブル（コイルケーブル）。**大きなデスクマット**の上
- 縦型マウスかトラックボール、**モニターライト**（画面の上に載る棒状の灯り）
- **ヘッドホン**はハンガーに掛けてある。**小さなスピーカー**が2つ
- 画面には**黒い背景のエディタ**（色つきのコード）、**ターミナル**（緑・白の文字が流れる）、ブラウザ（ドキュメント）、チャット
- 小物：**ラバーダック**、フィギュアやガンプラ、付箋、メモ帳とペン、ケーブルの束、マイコンの基板、モバイルバッテリー、スマホのスタンド、**マグと受け皿**

### 1.2 机のまわり
- **昇降デスク**（脚が2本の金属フレーム、天板は木）。机の裏にケーブルトレー
- **メッシュのオフィスチェア**（背もたれが高く、キャスター）。背にパーカーが掛けてある
- 机の下：PC本体（ガラス越しにファンが光る）、足置き、ゴミ箱
- **間接照明**：モニターの裏のLEDテープ、棚の下のLED、壁のネオンサイン（`</>` など）
- **ペグボード**か**有孔ボード**に工具・ケーブル・ヘッドホン
- **ホワイトボード**（設計の図、TODO）、技術書の並ぶ**本棚**（背表紙に動物の絵の本も）、**観葉植物**（ポトス、モンステラ、サボテン）

### 1.3 コーヒー
- **ハンドドリップ**：細口のケトル（温度が表示される）、手挽きミル、スケール、ドリッパー、サーバー
- 小さな棚かワゴンに道具がまとめてある。豆の袋、ペーパー、マグがいくつか

### 1.4 暮らし（ワンルームの残り）
- **ベッド**（低め。くしゃっとした掛け布団、クッション）、**ラグ**
- 小さなキッチン（IH 1口、ケトル、冷蔵庫の上に電子レンジ）、または壁ぎわのミニキッチン
- 洗濯物（ハンガーに数枚）、段ボール（届いた荷物）、ゲーム機、本の山、床置きのフロアランプ
- 窓：カーテン半開き、**外は夜の街**（マンションの灯り、遠くの電車）

## 2. 全体のルール

### 2.1 雰囲気（いちばん大事）
- **cozy ＝ あたたかい光の島がいくつか＋暗がり**。部屋全体は暗く、光は「デスク」「ベッドわきのランプ」「キッチンの手元灯」の3つだけ。そこにモニターの青白い光とLEDの紫が混ざる
- **小さな動きがたくさん**：キーを打つ指、流れるターミナル、マグの湯気、PCのファン、植物がかすかに揺れる、カーテン、窓の外の電車、雨粒（入れるなら）
- **ゆっくり**：人は急がない。伸びをする、コーヒーを一口、窓の外を見る
- **散らかりすぎず、きれいすぎず**：生活感は「ちょっとだけ」（掛けたパーカー、マグ2つ、床の段ボール1つ）

### 2.2 色
| 用途 | 色 |
|---|---|
| 壁・天井 | 夜の白い壁 `#d9d4cc`（光が当たると `#efe6d6`）、天井 `#cfc9c0` |
| 床 | 明るい木のフローリング `#b48a5e`、ラグ `#5a6270`（グレー）か `#b9a68a`（ベージュ） |
| 木 | 天板オーク `#c49a6c`、棚ウォルナット `#6b4a35` |
| 黒 | デスクのフレーム・モニター・機器 `#1e1f23`〜`#2b2d33` |
| 光 | 電球色 `#ffc98a`、モニター `#9fc4ff`、LEDテープ `#8b6cff`〜`#ff6ca8`、PCのファン `#5ad1ff` |
| 差し色 | キーキャップ（オレンジ `#e8673c`、クリーム `#efe3c8`、ミント `#9fd6c2`）、植物 `#5f8f4a` |
| 画面（エディタ） | 背景 `#1e2230`、キーワード `#c792ea`、文字列 `#c3e88d`、関数 `#82aaff`、コメント `#676e95` |

### 2.3 大きさ（ちび縮尺）
- 部屋：**8畳くらいのワンルーム**＝ 幅 3.6 m × 奥行 3.6 m（**2.75 × 2.75**）＋キッチンの張り出し。天井 2.4 m（**1.8**）
- 机 幅 1.4 m × 奥行 0.7 m、高さ 0.72 m（**1.06 × 0.53、高さ 0.55**）
- 人 **1.3**、椅子の座面 **0.36**、ベッド **1.5 × 0.75**、高さ 0.3
- 物が小さいので、キーボード・マグ・ケーブルは**少し大きめ**に作って読めるようにする（だいたい 1.2 倍）

### 2.4 見せ方
- **断面ジオラマ**：奥の2面の壁＋床。手前の2面と天井はなし。床と壁の厚み（切り口）を見せる。台座の下は少し影
- カメラは**斜め上から**、部屋のまわりをゆっくり回せる。ズームで机に寄れる（キーボードや画面の文字が読めるくらい）
- 背景は夜の色の無地。窓の外だけ、遠くの街の絵（灯りの点）

## 5. 人：コーヒーを飲みながらプログラミングする人

ひとり。パーカーかスウェット、靴下、ヘッドホン（首にかけたり、着けたり）。

### 5.1 一晩のくり返し（約 3 分で一周）
1. 机でコードを打つ（指が動く、画面の文字が増える）— いちばん長い
2. ときどき：マグを持ち上げて一口、画面を見て止まる（考える）、頬杖
3. ターミナルにエラー（赤い文字）→ ラバーダックを見る → 打ち直す → 緑の文字（テストが通る）→ 小さく伸び
4. マグが空になる → 立ってワゴンへ → ケトルでお湯、ミルで豆を挽く、ドリップ（湯気）→ 窓の外を見ながら一口 → 机に戻る
5. 夜が更けると、ベッドわきのランプだけ点けて…（物語を入れるならここで終わり）

### 5.2 動きの作り
- カフェの人（`cafe/src/` のキャラ）の体と顔を使い、**座る・打つ・飲む・伸び・歩く・注ぐ**の動きを足す
- 打鍵は指を細かく（腕の小さな上下）＋キーボードのキーが沈む＋画面の文字が増える、の3つを合わせる

---

## 6. 光（cozy の要）
- 空間全体は暗い青の環境光（かなり弱く）。主役の光は：
  1. **デスクのモニターライト**（電球色、天板に光の溜まり）
  2. **モニター2枚**（青白い面光、人の顔と手前の机を照らす）
  3. **LEDテープ**（モニター裏の壁と天井に紫〜ピンク）
  4. **ベッドわきのランプ**（電球色の小さな光、ベッドと壁）
  5. **キッチンの手元灯**（コーヒーを淹れるときだけ点く）
  6. 窓の外の街の光（ごく弱い）
- 影は 1〜2 本だけ（デスクライトとランプ）。あとは光の溜まり（バンコクの `lightPools` を壁にも使えるように）
- 少しだけ**ブルーム**（画面とLEDがにじむ）。重くなるなら halo（バンコクの光の粒）で代用

## 8. 技術メモ
- 動かない物はまとめて焼く（`bakeStatic`）。キーボードのキー、画面、湯気、ファン、人だけが動く
- 画面のキャンバスは 1 枚の大きなテクスチャ（2枚のモニター＋ノートPCの3面ぶん）を描き換える。毎フレームではなく、文字が増えるときだけ
- レンダラーは 1 つ、ほかのページと同じ（メモリに気をつける）
- 小物はインスタンス（キー、本、ペン、ケーブルの粒）
- ページ：`room/index.html`（部屋）、`room/parts.html`（パーツのカタログ）

## 12. 物語「雨の夜のバグ」（案・3〜4分）
1. 23:40、雨。机でコードを書いている。猫はベッドで丸くなっている
2. テストが赤い。何度か直すがまだ赤い。頬杖、ラバーダックを見る、ため息
3. 猫が机に乗り、キーボードを踏む（`aaaa`）。画面の前に座る。なでて降ろす
4. マグが空。立ってコーヒーを淹れる（ミル・ケトル・ドリップ、湯気）。窓の外の雨と電車を見ながら一口
5. 机に戻り、ふと気づいて1行直す → テストが緑。小さくガッツポーズ、伸び
6. 1:10。モニターを消し、デスクライトを消す。ベッドわきのランプだけ。猫と一緒に寝る → 雨の音だけ → 朝まで飛ばして最初に戻る
- 地の文＋ひとこと（古都・カフェと同じ `koto/src/story.js`、日本語/English）
