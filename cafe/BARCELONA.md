# バルセロナの街 — サグラダ・ファミリアのまわり（設計 v0.1・2026-10-29）

今のバルセロナ（`cafe/barcelona.html`）は、聖堂とカフェはできているが、まわりの街が「箱に窓の模様を貼っただけ」で、広場と池も平らな面のまま。
**バルセロナの雰囲気が伝わる街**にするため、ここで部品を決めてから、カタログ（`cafe/parts.html` に「バルセロナの街」の棚を足す）で1つずつ作り、最後に街に並べる。

聖堂（`cafe/SAGRADA.md`）はそのまま。縮尺も同じ（**1 m ≒ 0.76**、人 1.3）。

## 0. 決定事項（2026-10-29 回答）
1. **ガウディ大通りを入れる**：広場の北の角から斜めにのびる並木道。両側にお店とテラス、ファルケスの街灯
2. **お店は全部**：パン屋・果物屋・タパスのバル・アイス屋・薬局・お土産屋・花のキオスク・新聞のキオスク
3. **建物は全部細かく**：どの区画もバルコニーやよろい戸まで。くり返す部品は型ごとに1回作ってインスタンスで並べ、重くしない

### 1.2 ガウディ広場（Plaça de Gaudí）
- 生誕のファサードの向かい、マリーナ通りをはさんだ公園。**池に聖堂が映る**撮影の名所
- 曲がりくねった小道、芝生、ベンチ、木陰。地中海の木や花
- 池のまわりは観光客の写真、散歩、犬の散歩、子ども

### 1.3 ガウディ大通り（Avinguda de Gaudí）
- サグラダ・ファミリアからサン・パウ病院まで**斜めに走る、半分歩行者の並木道**（車止めのボラード、車はほぼ入れない）
- **カフェのテラスとお店**が並ぶ。昔からの近所の人の集まる店も
- **ペレ・ファルケスのモデルニスモの街灯**（1906年の作。1本の柱に5つの灯り「Cinc d'oros」。1985年にここへ移された）

- 新聞・雑誌のキオスク、花のキオスク

- 薬局の**緑の十字のネオン**、バルのテラスの赤いパラソル、市場の果物の山
- 通りの名前の板（角の壁に、白地に黒い文字）

## 2. 今の街の問題
1. 区画のビルが**1つの押し出しの形＋窓の模様**。バルコニーも1階のお店もなく、遠くから見ても「バルセロナ」に見えない
2. どの区画も同じ高さ・同じ色。屋上が平らなだけ
3. 広場は**砂利の大きな平面**に芝生の四角。池は鏡の面＋丸い縁だけで、まわりの作りがない
4. 人の動きが少ない（観光客4人、犬の散歩、子ども2人、ベンチの人）。お店の出入りがない
5. 通りの小物がほとんどない（街灯が数本、車が5台）

## 3. 作る部品（パーツ）

### 3.1 建物（アシャンプラの家）— いちばん大事
**階ごとに組み立てる部品**にして、組み合わせで何通りもの建物を作る。

| 部品 | 中身 | ばらつき |
|---|---|---|
| **B1 正面の1スパン**（窓1つ分、幅 約3 m） | フランス窓、よろい戸（開・半開・閉）、鉄のバルコニー（1つずつ／横に長い） | よろい戸の色（緑・茶・灰青）、手すりの形（まっすぐ・曲線） |
| **B2 トリブナ** | 2〜4階分の張り出し窓（木とガラス、または石） | 木・石・鉄とガラス |
| **B3 1階の店先** | 大きな開口（四角／アーチ）、日よけ、看板、ガラス | §3.2 のお店ごと |
| **B4 中2階・コーニス・屋上** | 帯の飾り、軒の出、屋上の手すり、物置、洗濯物、植木 | 屋根の形3種 |
| **B5 角の建物** | 切り落とした角に正面、角に店の入口と通りの名前の板 | |
| **建物の型 6つ** | 組み合わせの決まった型 | |

建物の型（案）：
1. **クリームの石の家**（よろい戸は緑、細いバルコニー、中央に木のトリブナ）— いちばん多い
2. **黄土色のしっくいの家**（長いバルコニー、茶のよろい戸）
3. **淡いピンクの家**（曲線の手すり、花の鉢がたくさん）
4. **赤茶のレンガと白い窓枠の家**（工場風、上に給水塔）
5. **モデルニスモの家**（曲線の軒、色タイルの帯、石のトリブナ）— 広場に面して1〜2軒だけ
6. **新しめの白い家**（簡素なガラスの手すり）— 少しだけ混ぜて今の街らしく

区画は **建物を通りに沿って並べたもの**として作る（区画ごとに型と高さと色を少しずつ変える）。中庭側は簡素に。

## 4. 配置（案）
今のジオラマの範囲（x −120〜160、z −110〜110）はそのまま。

```

  ┌─────────┬───┬──────────────┬───┬────────────┐
  │ 区画    │   │ 区画           │   │ 区画（ガウディ大通りが │
  │         │ サ│                │ マ│  斜めに入る：お店とテラス）│
  ├─────────┤ ル├──────────────┤ リ├────────────┤
  │ 区画    │ デ│  サグラダ・    │ ー│ ガウディ広場（池・小道・  │ カ
  │         │ ー│  ファミリア    │ ナ│ 遊具・ベンチ）           │ フェ
```

- **広場に面した区画の通り側**と**ガウディ大通り**に、お店と細かい建物を集める（いちばん見られる場所）
- 遠くの区画は同じ部品の簡単な版（バルコニーは板1枚、窓は模様）にして軽くする

## 5. 重さの工夫
- 建物は**部品を型ごとに1回だけ作り、インスタンスで何度も並べる**（バルコニーや窓は数千になるので必ず）
- 遠い区画は簡単な版。夜の窓の灯りは今と同じ光るテクスチャ
- 人は今の仕組み（`koto/src/people.js`）。増やすのは 40〜60人くらいまで
