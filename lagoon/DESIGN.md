# ロングテールの入り江 Longtail lagoon — 設計 v0.1（2026-11-10）

目的：**石灰岩の崖にかこまれたエメラルドの入り江と、その上に浮かぶロングテールボート**を、手のひらサイズのジオラマにする。手本はユーザーの写真（タイ・クラビ県、ピピ・レ島の **ピレ・ラグーン Pileh Lagoon** と思われる構図）。
方針：写真の **構図・色・光はそのまま**。形は Tiny Worlds の決まりどおり、**丸く、ずんぐり、おもちゃのように**。
進め方：**設計（この文書）→ 試作（`lagoon/index.html`）→ 確認 → 仕上げ・動画・トップページ**。

## 1. 写真の分解（見えているものをすべて）

### 1.1 構図
- 縦長（3:4）。**ボートの船尾側から舳先ごしに**、入り江の奥を見る。目の高さは人の頭くらい
- 画面の縦の割合：**上 1/6 が空、まん中の 1/2 が崖、下 1/3 が水とボート**
- **舳先が画面の下中央から、少し右上へ**のびる。舳先の柱の先（緑の布）は画面のほぼ中央、地平線（崖の根元）のすぐ上
- **太陽は左 1/4、崖のすき間**。そこから光の筋が放射状に出る
- 左の崖は**逆光で暗い**、右の崖は**光を受けて明るい**。この明暗の差が写真の主役
- 旅行者は舳先の左寄りに座り、体は右、顔は上（太陽の方）

### 1.2 空
- 高い所は**淡い水色**、下へいくと白っぽく、太陽のまわりだけ**黄みがかった白**に飛んでいる
- 雲はない。もやで遠くの崖がうっすら青くかすむ

### 1.3 崖（石灰岩のカルスト）
| 部分 | 写真で見えるもの |
|---|---|
| 形 | **ほぼ垂直の壁**。上は丸くふくらんだ頭、てっぺんは木でもこもこ。右の崖のさらに奥に、**もう一段高い頭**がのぞく |
| 根元 | 水面のすぐ上が**えぐれて（ノッチ）**、黒っぽい帯になっている。崖の足は水に直接立つ。浜はない |
| 岩肌 | 明るい**灰白〜クリーム色**。**縦の筋**（雨のしみ）が上から下へ。**黄土色・橙のしみ**、**濃い灰色の筋**がまじる |
| 緑 | 上の方ほど**緑が厚く**、**壁にそって下へ垂れる**。日の当たる所は**黄緑**、影は**深緑**。岩の出っぱり（棚）にも茂み |
| 左の崖 | 逆光で**濃い緑と黒っぽい灰色**。輪郭が太陽の光でにじむ |
| 右の崖 | **一番大きく、明るい**。岩の白と緑が半々、縦の筋がはっきり |
| 遠くの崖 | 太陽の下、かすんだ**青緑**の影 |

### 1.4 水
- **鮮やかなターコイズ**。手前は少し濃い**青緑**、まん中は明るい**エメラルド**
- **太陽側（左）の水面がきらきら光る**（小さな白い点がたくさん）
- 崖の根元に**崖の緑が映った暗い帯**
- 波はほとんどない。細かいさざ波だけ

### 1.5 ロングテールボート
| 部分 | 写真で見えるもの |
|---|---|
| 船体 | **細長い木の舟**。板張りで、**だいだい〜赤茶**の木目。ふちの板（舷）は少し濃い |
| 舳先 | **高く反り上がる**。先は四角い柱になって、てっぺんに**緑の布**が巻いてある |
| 飾り | 柱の下の方に**色とりどりのリボンと花輪**（ピンク・水色・黄・赤・緑）。お守りの布 |
| 甲板 | 舳先の近くは**平らな板張り**で、人が座れる |
| 見えないもの（よく知られた形） | 船尾に**車のエンジン**をそのまま載せ、**長い棒の先にスクリュー**。船頭が棒を握って舵をとる。日よけの屋根つきの舟もある |

### 1.6 人
- 舳先に座る旅行者：オレンジの水着、サングラス、長い髪、裸足、両手を板について顔を上げる

## 2. 可愛くする決まり

1. **角を全部丸くする**：崖の頭はお団子、ボートのふちも丸い。とがっていいのは舳先の反りだけ
2. **ずんぐりさせる**：人は **2.5 頭身**（背 0.58）。ボートは人の 4.5 倍の長さ
3. **崖をお菓子のように**：垂直の壁は残すが、頭はぷっくり、縦の筋はやわらかい色のしみ。木はブロッコリーのようなもこもこ
4. **遠近をうそにする**：本当の崖は人の 100 倍以上あるが、ここでは **15〜25 倍**。台の上に入り江が丸ごとのる
5. **色を減らしてやさしくする**：下の色見本の中だけで作る。黒は使わず深緑と紺
6. **水は宝石のように**：濃淡のはっきりしたターコイズと、太陽側のきらめき。台の手前の**断面は透きとおった青のグラデーション**で、ジオラマらしさを出す
7. **台にのせる**：世界全体が角丸の木の板の上。空は背景のグラデーションと太陽だけ

## 4. パーツの一覧

- **崖**：縦に長い回転体を、角度ごとの凹凸で崩す。根元のノッチ、ぷっくりした頭。岩の色・縦の筋・しみ・垂れる緑はシェーダーで位置と向きから描く（頂点を増やさずにすむ）
- **木**：崖の頭と棚に、ブロッコリーのような丸の集まり（1つのメッシュに合体）
- **水**：入り江の形の平面。色は崖からの距離と深さで決め、細かいさざ波を法線だけで描いて、太陽のきらめきを出す。台の手前に水の断面
- **太陽**：崖のすき間の奥に、光の筋のある円（加算合成の絵1枚）
- **ロングテールボート**：断面をつないだ船体（板の段ごとに色を変える）、甲板、舷、反り上がる舳先の柱、緑の布、リボンと花輪、船尾のエンジン・長い棒・スクリュー、日よけ屋根（遊覧の舟だけ）
- **人**：舳先の旅行者、船頭（主役の舟の船尾に座る）、遊覧の舟の客、カヤックの2人、シュノーケルの人（オレンジの救命胴衣）
- **鳥**：崖のまわりを回るアナツバメ

動くもの：主役の舟がゆっくり揺れる／遊覧のロングテールが入り江をぐるりと回り、白い航跡を引き、スクリューが回る／カヤックがゆっくり進む／シュノーケルの人が浮き沈みし、ときどき手を振る／舳先のリボンが風に揺れる／旅行者がときどき髪をかき上げる／アナツバメが崖のまわりを回る／水面のきらめき。

### 4.1 水の中（ユーザーの要望 2026-11-10「海に透明度」「魚も」「波も」）
- **透明な水**：真上から見ると澄んで、斜めに見るほど・崖の映りほど濃くなる。台の手前の断面も**ガラスのように透ける**
- **海底**：白い砂。浅い砂州と深いくぼみ、崖の足には岩くず。深いほど青緑に沈み、**光の網（コースティクス）**がゆれる
- **サンゴ**：崖の足ぞいと、シュノーケルの人たちの下の**サンゴの庭**。ノウサンゴ（黄）、枝サンゴ（桃）、ウミウチワ（紫）、管（橙）、岩
- **魚**：チョウチョウウオ（黄）、ナンヨウハギ（青）、オヤビッチャ、ブダイ（緑）、イワシの群れ、オレンジの小魚。群れごとに輪を描いて泳ぎ、尾をふる。**小さなツマグロ（サメ）**が1匹、ゆっくり回る
- **波**：ゆるいうねりが3方向から。**ボート・カヤック・シュノーケルの人はうねりに乗って上下し、傾く**。崖の足には白い波の泡

## 5. 作り方

- **ページ**：`lagoon/index.html`、部品は `lagoon/src/`。舞台は `room/src/stage.js`、部品の合体は `fuji/src/kit.js` を再利用
- **メモリ**：崖・木・動かないものは頂点カラーで1つのメッシュにまとめる。ボートは形を1回作って複製（形は共有）。人は材質を色ごとに共有。影は 2048 を1枚
- **灯り**：太陽（崖のすき間の奥から、低く、暖かい）と、空の水色・水のターコイズの照り返し（半球光）。ブルームは太陽ときらめきが光る程度
- **魚**：全部で1つのインスタンスメッシュ（色は1匹ずつ）。サンゴは1つのメッシュ。海底は1枚の板
