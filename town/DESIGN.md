# 道と街のライブラリ — 設計 v0.1

Tiny Worlds の**どの街でも使える**、道路・車・建物・道ばたの物の共通パーツ。最初の利用先は「空港 → 那覇の海」のドライブ。あとで別の街（東京の下町、雪の町、ヨーロッパの港町など）を作るときも、同じ部品に**地域の型（スタイル）**を差し替えて使う。

置き場所：`tiny-worlds/town/`（各世界から `../town/...` で読み込む）。カタログページも `town/index.html` に作る（海の生き物と同じく、分類タブ＋組み合わせた見本の場面）。

---

## 0. 決定事項

- **ドライブの見せ方**：両方。カタログと全体図は区間を全部並べた細長いジオラマ、ドライブ本番は車を中心に景色が流れて区間が順に入れ替わる方式（同じ区間タイルを両方で使う）
- **車の大きさ**：空港と同じ「ちび」（乗用車の長さ2.1）。空港の車・人とそのまま並べられる
- **交通の細かさ**：簡単なルール — 信号で止まる、前の車との車間を保つ、路線バスはバス停に寄る、横断歩道の人を待つ
- **沖縄らしさ**：モノレールを入れる。空港駅から市街地の上を高架で走る（①空港通り・③国道の区間）

## 1. 全体のルール

### 1.1 見た目
- 空港・海と同じ**やわらかいローポリ**。角は少し丸め、色はパレット＋地域の差し色
- 文字（店の看板・標識）は実在しない名前にする。ブランドのロゴや実在の店名は使わない
- 窓・ドア・看板などは**モジュール**（同じ部品を並べて建物を組む）。遠くからでも形で何の建物かわかるようにする（ガソリンスタンドの屋根、コンビニの横長の看板帯、など）

### 1.2 大きさ（空港と同じ「ちび」縮尺）
- 人の身長 1.3 = 1 unit ≈ 1.3m 相当
- 車は空港の車に合わせて**短め**：乗用車 長さ2.1 × 幅1.0 × 高さ1.1（実寸の比率だと長さ3.5になる）
- 車線の幅 2.6（空港の道路と同じ）、歩道 1.2〜2.0
- 建物の1階分の高さ 2.6（空港の天井と同じ）。2階建て住宅 ≈ 5.6、5階建てアパート ≈ 13.5

### 1.3 道のしくみ（タイル）
- 道は**区間タイル**の組み合わせ：1タイル = 長さ 12（直線）を基本に、カーブ・交差点・坂などを同じ格子（12 × 12）にはめる
- 各タイルは「車線の中心線」（車が走る道すじ）と「歩道の道すじ」を持ち、つなげると街全体の道順になる（空港の `roundedPath` と同じ考え方）
- 路面標示（白線・黄線・横断歩道・停止線・矢印）は路面のテクスチャではなく、薄い板を重ねる（近づいてもにじまない）
- 左側通行（日本）。地域の型で右側通行にも切り替えられるようにしておく

### 1.4 動きの種類
| 種類 | 中身 | 使うもの |
|---|---|---|
| 走る | 道すじに沿って進む。カーブで減速、前の車との車間を保つ（空港の `vehicleBlocked` と同じ考え方） | 車、バス、バイク、自転車 |
| 止まる・発進 | 信号、一時停止、横断歩道の人、バス停 | 車、バス |
| 曲がる合図 | ウインカーの点滅、ブレーキランプ | 車 |
| 乗り降り | ドアが開く、人が乗る・降りる | バス、タクシー、レンタカー |
| 揺れる | 風で揺れる（ヤシ、サトウキビ、旗、のぼり） | 植物、旗 |
| 光る | 信号の切り替え、夜の街灯・窓・看板 | 設備、建物 |
| 歩く | 歩道を歩く、横断歩道を渡る、店に入る | 人 |

### 1.5 地域の型（スタイル）
同じ部品に、色・屋根・素材・小物を差し替える。

| 型 | 特徴 |
|---|---|
| **沖縄**（最初に作る） | 平らな屋根のコンクリート住宅、屋上の給水タンク、赤瓦の屋根（古い家）、花ブロックの塀、シーサー、ヤシ並木、白っぽい外壁、強い日差し |
| 日本の街（汎用） | 瓦やスレートの屋根、電柱と電線が多い、ブロック塀、自販機、狭い道 |
| 雪の町（他の街用） | 急な屋根、雪囲い、除雪車、つらら |
| ヨーロッパの港町（他の街用） | 石畳、オレンジ屋根、右側通行、路面電車 |

## 3. 那覇の道：空港 → 海（最初の使い道）

空港の車寄せを出たレンタカーが、海の世界の駐車場に着くまで。実際の那覇を参考にした**架空の道順**。

```
 [空港] 車寄せ ─→ ① 空港通り ─→ ② レンタカー営業所 ─→ ③ 国道（市街地）─→ ④ 住宅地 ─→ ⑤ サトウキビ畑 ─→ ⑥ 海が見える坂 ─→ ⑦ ビーチの駐車場 [那覇の海]
```

| 区間 | 道 | 見えるもの | 起きること |
|---|---|---|---|
| ① 空港通り | 4車線、中央分離帯にヤシ | 案内標識（那覇市街 ／ 海の方面）、モノレールの空港駅と高架 | タクシーとバスが空港から出てくる |
| ② レンタカー営業所 | 脇道＋広い駐車場 | 同じ白いミニバンがずらり、送迎バス | ハナの一家が送迎バスを降り、わナンバーのミニバンを受け取る |
| ③ 国道（市街地） | 4車線、信号の交差点 | コンビニ、ガソリンスタンド、アパート、頭上をモノレール、のぼり旗 | 赤信号で止まる、横断歩道を人が渡る、路線バスがバス停に寄る |
| ④ 住宅地 | 2車線 | 給水タンクの白い家、花ブロックの塀、門のシーサー、洗濯物、公園のガジュマル | 自転車の子ども、軽自動車 |
| ⑤ サトウキビ畑 | 2車線、電柱が並ぶ | 一面のサトウキビ（風で波打つ）、赤瓦の古い家、防風林 | 軽トラがゆっくり、風の音（後で） |
| ⑥ 海が見える坂 | 2車線の上り坂 → 下り | 坂の頂上で視界が開けて、エメラルドの海が見える（**見せ場**） | カメラが少し上がって海を見せる |
| ⑦ ビーチの駐車場 | 駐車場 | 土産物屋、ドライブインの店、防風林、浜への小道 | 車が止まり、一家が降りる → 海の世界へ |

帰り道は逆順。夕方にすると、⑥で夕日の海、③で街の灯が見える。

## 4. 作る順番（案）

1. 共通のしくみ：道のタイル（直線・カーブ・交差点・坂）と道すじ、車が道すじを走るしくみ（車間・信号で止まる）
2. 代表を1つずつ作って形と動きを確定：**道（直線＋交差点）→ 車（ミニバン）→ 建物（コンビニ）→ 設備（信号）→ 自然（サトウキビ畑）**
3. 残りの部品（全部）
4. カタログ `town/index.html`（分類タブ＋見本の場面：交差点、住宅地、畑の道）
5. 那覇の道（§3）を組み立て、空港と海をつなぐ

## 5. 技術メモ

- 建物はモジュールを結合して1つの形にする（空港の `bakeStatic` と同じ考え）。同じ建物はインスタンス描画
- 窓の明かりは頂点カラー＋夜だけ光る材質（空港の夜景と同じしくみ）
- 道のタイルは「形」と「道すじ（車線・歩道）」をセットで返す。並べると道すじが自動でつながる
- 車の動きは空港の `Vehicle`（道すじに沿う、前の車で止まる）を一般化して、信号と交差点の優先を足す

## 6. 決めたいこと（2026-10-28 回答済み → §0）

1. **ドライブの見せ方**：①長い一本道のジオラマ（区間を全部並べた細長いブロック）／②ランニングマシン方式（車は画面の中央、景色が流れてきて区間が順に入れ替わる）／③両方（カタログは①、ドライブ本番は②）
2. **車の大きさ**：空港と同じ「ちび」（短め）／少し実寸寄り（長さ3.0くらい）
3. **交通の細かさ**：見た目だけ（信号は光るが車は止まらない）／簡単なルール（信号で止まる、車間を保つ、バス停に寄る）／もっと細かく（右折待ち、歩行者優先、救急車に道を譲る）
4. **沖縄らしさ**：モノレールを入れる／入れない（入れると街の上に高架が通り、空港駅から見える）
