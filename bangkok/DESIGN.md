# バンコクの夜市の通り — 設計 v0.1（ドラフト・2026-10-31）

目的：**バンコクの夜の屋台通り**を、小さな世界としてひとつ作る。湯気、炭火、中華鍋の炎、ネオン、裸電球、プラスチックの椅子、トゥクトゥク。歩くと次々に違う食べ物が見えてくる通り。
方針：いつもどおり **設計（この文書）→ パーツ（カタログ）→ 屋台キット → 通りに並べる** の順。縮尺はカフェやバルセロナと同じ（**1 m ≒ 0.76、人 1.3**）。
世界地図には **BKK（バンコク）** を足し、ミニ空港からの路線にする（§9）。

## 1. 調べたこと（どんな通りか）

### 1.1 ヤワラート通り（中華街）
- 夜になると**車道の端まで屋台が出る**大通り。両側は**3〜5階のショップハウス**（1階が店、上が住まい）
- **縦長の看板が建物から通りに突き出し、何枚も重なる**。赤・金・白の中国語とタイ語の文字、ネオンと電球。夜の写真で一番目立つもの
- 金の店（金行）が多く、**真っ赤な店内に金色の光**
- 食べ物は海鮮、フカヒレ、焼き栗（黒い砂で炒る）、クイジャップ（胡椒のスープの巻き麺）、ツバメの巣の飲み物
- 車道にはトゥクトゥク、タクシー（ピンク・緑と黄）、バイクタクシー（オレンジのベスト）

### 1.2 鉄道市場（ロットファイ、ジョッドフェア）
- 広い敷地に**色とりどりのテントの屋根がずらりと並ぶ**。上から見ると**モザイクのような色の格子**（写真の定番）
- 屋台は四角いテント（白・赤・青・黄・緑の縞）の下。テントごとに裸電球かLEDの棒
- 古着、ビンテージ、レコード、雑貨の店も混ざる。奥にバーとライブの舞台

### 1.3 路地（ソイ）の屋台
- 歩道に**ステンレスの屋台車（ロットケン）**：ガラスのショーケース、車輪、横にガスボンベ
- **赤と青のプラスチックの丸椅子、折りたたみの金属テーブル**、テーブルの上に調味料4点セット（砂糖・唐辛子・ナンプラー・酢）、箸立て、ティッシュ
- 電柱から**からまった電線の束**。電球のコード、延長コード
- セブンイレブンの明かり、祠（サーンプラプーム：花輪とお供え）、野良犬が寝ている

## 2. 通りの形（案③の場合）

```
  北 ─────────────────────────────────────────────────────
   ショップハウス（金行・薬局・食堂）  縦の看板が通りに張り出す
  ═══ 歩道：屋台車がずらり ═══════════════════════════════
  ─── 車道：トゥクトゥク・タクシー・バイク（ゆっくり流れる）───
  ═══ 歩道：屋台車＋丸椅子のテーブル ════════════════════
   ショップハウス           │ 路地の入口（アーチの看板「夜市」）
  ─────────────────────────┘
                           │  テントの路地：色テントが2列 × 10張り
                           │  まん中を人が歩く。奥に小さな舞台と飲み物
                           └──────────────
```

- 大通り：長さ約 60（約80 m）、車道 2車線、歩道は屋台で半分ふさがる
- 路地：幅 約 6、長さ 約 30。テントは 2.4 × 2.4、高さ 2.6（人の縮尺）
- カメラの見どころ：①上から見たテントの色の格子 ②看板のネオンが重なる大通り ③屋台の炎と湯気のアップ

## 3. 色と光（パレット）

| 用途 | 色 |
|---|---|
| 夜空・影 | 紺 `#1d2440`、濃い紫 `#2a2350` |
| 看板 | 赤 `#d9342b`、金 `#e8b64a`、白、ネオンのピンク `#ff5ca8`・水色 `#5ce1ff`・緑 `#5cff8a` |
| テント | 赤白の縞、青白の縞、黄、緑、オレンジ（5色を規則的にくり返す） |
| 屋台車 | ステンレス（銀）、ガラス、赤い文字の看板 |
| 椅子 | プラスチックの赤 `#e0453a`、青 `#3a7fd0` |
| 明かり | 裸電球の暖色 `#ffcf80`、LEDの白い棒、炭火のオレンジ `#ff7a2a` |

**光の作り方**（重くしない）
- 光る物は**発光マテリアル**だけで描く。本物のライトは「月」「通りの全体の暖色」「ネオンの色の弱い光」の3つほどに抑える
- 電球の列は **InstancedMesh**（1本のひもに電球30個でも1回の描画）
- 湯気・煙は半透明の板をビルボードで（屋台ごとに3〜5枚、使い回し）。炎は発光する小さな円すいが揺れる

## 8. 動くもの

- 車道：トゥクトゥク（3色・電球の飾り）、タクシー（ピンク、緑と黄）、バイク、屋台を引くバイク（サイドカー屋台）。ゆっくり流れ、人が渡ると止まる
- 屋台：炎（鍋をあおるたび）、湯気、炭の明滅、煙、ネオンの点滅（1〜2枚だけ切れかけでチカチカ）
- 人：屋台の前に**行列**ができて、買って、袋を持って歩く。丸椅子のテーブルが埋まったり空いたり
- 夕方 → 夜（案B②の場合）：空の色、看板が順に点灯、シャッターが上がり屋台が開く

## 9. 世界地図とのつながり

- `world/src/places.js` に **BKK（バンコク、13.75°N, 100.50°E）** を足し、路線に入れる。地図の模型は「トゥクトゥク」か「寺の塔（プラーン）」
- フライトページ：羽田 → バンコクの便（着陸の先がこの通り）は、通りができてから

## 10. メモリ（必ず守る）

- 同じ形はすべて共有（`mat()` のキャッシュ、ジオメトリのキャッシュ）。テント・椅子・電球・串・看板の板は InstancedMesh
- 屋台は種類ごとに1回作り、動かない部分は `bakeStatic` で結合
- 文字の看板は**1枚のキャンバス（アトラス）**に全部描いて、板ごとに UV で切り出す
- 湯気・煙の板は全屋台で20〜40枚を使い回す。レンダラーは1つ
