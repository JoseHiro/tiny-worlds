# Tiny Worlds 02 — 那覇の海（設計 v0.1）

目的：ハナの一家が旅行した先を、**透き通った沖縄の海**のジオラマとして作る。空港（World 01）とストーリーでつながる：空港に着いた家族がレンタカーで海へ向かい、海で遊び、お土産を買って、また空港へ戻る。

参考：以前の「Atoll Jelly」の画像 — 断面が見える水のブロック、水面の波紋、底に揺れる光の網目（コースティクス）、浅瀬から深みへのグラデーション、水上の小屋、上から見下ろすジオラマ。

進め方は空港と同じ：**設計 → パーツ・生き物のカタログ → 場面キット → 世界に組み込み → ストーリー**。

## 5. 水の作り方（技術メモ）

- **水のブロック**：上面は波の高さマップ（GPUで計算、クリックやボートの通過で波紋）、側面は断面として水深のグラデーション
- **屈折**：水の下の砂・サンゴを、水面の傾きでゆがめて描く
- **コースティクス**：水底に揺れる光の網目（水面の高さマップから計算）
- **色**：深さで浅瀬の水色 → 深い紺。浅い所ほど底が透けて見える
- **泡と白波**：波打ち際とリーフの縁に白い泡のライン
- 空港と同じ Three.js（WebGL）。重くなるので、波の計算の解像度と魚の数（インスタンス描画）で調整する

## 6. ストーリー（空港とつながる）

- **ハナの一家**：空港の那覇行きで出発 → （海の世界）レンタカーで駐車場に到着 → 浜でパラソル → ハナは浮き輪で浅瀬へ、ウミガメに出会う → パパはシュノーケルでクマノミを見る → 海の家でかき氷 → お土産屋で紅型の袋を買う → 車で空港へ → （空港）帰りの便で、ハナがその袋を持って帰る
- **グラスボートの船長**：1日に何度も船を出し、乗客に魚を見せる
- **ライフガード**：沖に出すぎた浮き輪を笛で呼び戻す
- 小さな出来事：イルカの群れ、夕方のスコール、夕日、夜光虫

## 6.5 水のプロトタイプ ✅（2026-10-28、`naha/index.html`）

- 海のブロック 90×60。地形は、砂浜 → 波打ち際 → 礁湖（砂紋）→ サンゴ礁（岩のこぶ、礁を横切る水路）→ 崖 → 外洋（水深約9）。海岸線と礁の縁はゆるく波打つ
- 水面：GPU上の波紋シミュレーション（256×256）＋常に揺れるうねり。水面をクリックすると波紋が広がる。浮き輪の子どもからも小さな波紋が出る
- 色：水の下を一度描いてから、波の傾きでゆがめて重ねる（屈折）。赤い光ほど早く吸収されるので、浅瀬は砂が透けたエメラルド、礁はターコイズ、外洋は濃い青になる（白く濁らない）。空の映り込み、太陽のきらめき、波打ち際の白い泡、礁の縁の白波
- 光の網目（コースティクス）：海底・サンゴ・魚に、2つの大きさの網目が重なって揺れる。深いほど弱く、色は青緑に寄る
- 断面：水の層（深いほど濃い色、上から差し込む光の筋）と、地層（砂 → 岩の帯）
- 大きさの目安：ヤシ7本、パラソル3つ、人、浮き輪の子ども、仮のサンゴ（丸・枝・テーブル）、小魚の群れ3つ（150匹）。サンゴと魚は形を決める前の仮置き
- 調整用のつまみ：波の高さ・透明度・光の網目の強さ・昼／夕方

## 6.6 海の生き物を配置 ✅（2026-10-28、`naha/src/sealife.js`）

- 共通ライブラリ `sealife/` の生き物を、水深から決まる「すみか」ごとに置く（約550匹）
  - **浅瀬**（深さ0.6〜1.2）：ツマグロ2匹が巡回、アカエイ・ヤッコエイが砂の上、チンアナゴの原っぱ（56本）、アオウミガメ（浮き輪の子の近く）、ハコフグ、タコクラゲ、ヒトデ、ナマコ、波打ち際のヤドカリとカニ
  - **サンゴ礁**（深さ1.3〜1.6）：イソギンチャクのクマノミ一家×3、ナンヨウハギの群れ×2、サンゴの上のデバスズメダイ／ルリスズメダイ、チョウチョウウオとツノダシのペア、ブダイ、ハリセンボン、ハタとウツボ（岩から顔を出す）、昼寝中のネムリブカ、タイマイ、アオリイカ3匹、シャコガイ、ガンガゼ、ウミウシ、タコ
  - **外洋**（深さ約9）：マンタ（8の字）、マダラトビエイ3匹、ギンガメアジの竜巻、イワシのベイトボールとマグロ、ミズクラゲ。空にカモメ
  - **できごと**：イルカの群れ（45〜75秒ごと、ジャンプしながら外洋を横切る）、ジンベエザメ（2〜3分に一度、コバンザメ付き）。ブロックの断面から入ってきて反対の断面へ抜ける（ブロックの外は切り取って見せない）。パネルに「いま通っているもの」を表示
- 驚く動き：ツマグロ・エイ・浮き輪の子が近づく、または水面をクリックすると、チンアナゴが引っ込み、小魚の群れが散り、ハリセンボンがふくらみ、ウツボが穴に戻る
- 生き物にも光の網目（コースティクス）がかかる。歩くもの（カニ、ヤドカリ、ウミウシ、タコ、エイ）は凸凹の海底に沿って動く
- 見る場所ボタン：全体／浅瀬（チンアナゴ）／サンゴ礁（クマノミのイソギンチャク）／外洋／断面（水の断面が水槽のガラスのように透ける）
- 残り：サンゴは仮のまま（場面キットで作り直す）、ジュゴンとタツノオトシゴ（まれ）はまだ置いていない、夜の行動（ネムリブカが泳ぎ出す）は未対応

## 6.7 波 ✅（2026-10-28、`naha/src/waves.js`）

沖縄の海は、岸のすぐ外にサンゴ礁が張り出した「裾礁」。外洋のうねりは礁の縁でくだけ、礁の内側（イノー）は静か、浜には小さな波が寄せては返す。この順番をそのまま作る。

| 場所 | 波の高さ（目安・つまみ1のとき） | 形 | 見え方 |
|---|---|---|---|
| 外洋（崖の外） | 0.22 | 長いうねり。波長約9、周期約6秒。北（沖）から浜へ向かって進む | 丸い背のうねりがゆっくり通る。数本おきに少し大きい波（セット） |
| 礁の縁に近づく | 0.22 → 0.38 | 浅くなるので波が高く、短く、前が切り立つ | 波の背が盛り上がる |
| 礁の縁（くだける所） | 0.38 → 0.07 | 前がいちばん切り立った所で崩れる | 白波の帯が横に走り、しぶきが上がる。崩れた後ろに白い泡が残って消えていく |
| 礁の水路（x≈14） | くだけない | 深いので波がそのまま通る | 白波の切れ目（実際の海でも水路は白波が切れる） |
| 礁の内側（イノー） | 0.05 | 小さなさざ波＋残った波 | ほぼ鏡のように静か。透けて見える海底が主役 |
| 浜（波打ち際） | 0.07 | 寄せる波 | 水面ごと浜の斜面をはい上がって戻る（水際の白い泡の線も一緒に動く） |

- 波の向き：浜に向かってまっすぐ。海岸線と礁の縁が波打っているのに合わせて、波の筋も少し曲がる
- 波の高さのつまみ：全体の大きさ（0 で凪、2.5 で荒れ）。くだける強さとしぶきの量も一緒に変わる
- 断面：水の断面の上辺も波と同じ高さで動く（ブロックの縁で水面と断面がずれない）
- 浮き輪の子・海の生き物：浮き輪は波に合わせて上下する
- しぶき：くだける瞬間の波の頂に、白い粒が上がって落ちる（最大400粒）
- 実装メモ：波の式は GLSL（水面・断面）と JS（浮き輪・しぶき）に同じものを持つ。白波は「波の頂からの距離」で決め、ノイズでまだらにする。浜では小さなくだけ波＋水際の白い線とレース状の泡。昼の確認で 120fps

## 6.8 ハナの一日（海）✅（2026-10-28、`naha/src/story.js`）

道（`road/?leg=out`）から来ると自動で始まる。パネルの「ハナの一日を見る」でもいつでも見られる（約3分）。

1. 浜に到着、パラソルに荷物を置く
2. ハナが浮き輪で浅瀬へ → ウミガメが近づいてきて、ハナのまわりを泳ぐ（カメラが寄る）
3. パパがシュノーケルでサンゴ礁へ（うつ伏せで泳ぐ）→ イソギンチャクのクマノミ一家（横からのカメラ）
4. 海から上がって海の家へ、ハナはいちごのかき氷
5. お土産屋で紅型の袋を買う（ハナが袋を抱える）
6. 車に戻る →「帰り道へ」→ `road/?leg=back`

- 浜に置いたもの：海の家（トタン屋根、メニュー、かき氷機、テーブル、シャワー、「氷」の旗）、お土産屋、パラソル3つ
- 家族は水着（`swimKid` / `swimMum` / `swimDad`）。浮き輪の子はハナの一日のあいだハナになる
- 残り：サンゴは仮のまま（場面キットで作り直す）
