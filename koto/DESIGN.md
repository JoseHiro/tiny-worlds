# World 03 古都（京都・鎌倉のような町）— 設計 v0.1

寺と神社、石畳の参道、町家の並ぶ路地、川沿いの柳と桜、竹林の小径、海と路面電車（鎌倉）。人は着物で歩き、茶屋で団子を食べ、おみくじを結び、人力車が通る。**情緒**が主役の世界。

置き場所：`tiny-worlds/koto/`。建物・通りの部品は `town/` のライブラリに**「古都」の型（スタイル）**として足す（あとで別の古い町——金沢、倉敷、川越、奈良——にも使えるように）。人の服装は空港の `person()` に足す。

**実在の場所をそのまま写さない**：京都・鎌倉の「らしさ」を集めた架空の町にする（実在の寺社名・店名は使わない。大仏や五重塔のような「型」は使う）。

## 0. 決定事項

回答（2026-10-28）

- **町の性格**：京都と鎌倉を混ぜた**架空の古都**。山側に京都らしい寺社・町家・花街・竹林、海側に鎌倉らしい海・路面電車・大仏
- **場面**：A〜H を**全部**作る。順番は
  1. A 参道 ＋ B 境内（古都の中心。屋根・町家・寺の部品がここでそろう）
  2. F 石畳の路地（花街）
  3. C 千本鳥居 ＋ D 竹林
  4. G 海と路面電車 ＋ H 大仏
- **季節**：**最初から切り替えつき**（春・初夏・秋・冬）。木と花は同じ形で色だけ差し替えるしくみを最初に作る。時間（朝・昼・夕・夜）も同じ考え方
- **特別な装いの人**：舞妓さん・僧侶・神主・巫女も**入れる**。ちびの形で衣装の特徴（帯、袴、袈裟、かんざし）を丁寧に、白塗りなどは控えめに。敬意のある描き方にする（ふざけた動きはさせない）

## 1. 全体のルール

### 1.1 見た目
- これまでと同じ**やわらかいローポリ**。古都は**直線と水平の美しさ**が大事なので、屋根の反り、軒の深さ、格子の細かさに手間をかける
- 色は「和の色」を中心に。多色にしない
  - 木：焦茶 `#5a3f2e`、古材 `#7a5a40`、白木 `#d8c4a0`
  - 壁：漆喰の白 `#f2ede2`、土壁 `#c9a87c`、弁柄 `#8e3b2e`
  - 屋根：いぶし瓦の銀鼠 `#6d7178`、銅板の緑青 `#5f9a8a`、檜皮・茅 `#7a5a3a`
  - 差し色：朱 `#d9482b`（鳥居・欄干）、金 `#c9a24a`、藍 `#2f4a6b`、暖簾の色（藍・えんじ・生成り）
  - 自然：苔 `#6f8f4a`、竹 `#8fb06a`、桜 `#f6c4cf`、紅葉 `#d9542f`
- 細かい部品（格子、瓦の列、垂木、石畳）は**同じ形をたくさん並べる**（インスタンス描画）。細かくしても重くならないようにする

### 1.2 大きさ
- これまでと同じ「ちび」縮尺：人の身長 1.3、車 2.1、1階分の高さ 2.6
- 寺社は迫力のため**少し大きめ**（五重塔は高さ約18、山門は約9）。ただし通りは狭く、人との距離が近い

### 1.3 屋根のしくみ（古都の要）
建物の印象は屋根で決まるので、屋根を生成する部品を先に作る。

| **入母屋**（いりもや） | 上が切妻、下が寄棟。寺社の基本 | 本堂、拝殿、山門、旅館の玄関 |
| **宝形**（ほうぎょう） | 四角すい、頂に宝珠 | 鐘楼、手水舎、小さなお堂 |
| **反り** | 軒先が少し上がる曲線（寺社）、まっすぐ（町家） | — |
| 部品 | 鬼瓦、棟瓦、軒瓦の列、垂木の木口、懸魚（げぎょ） | — |
| 素材 | いぶし瓦（瓦の筋を形で）、銅板（緑青）、檜皮・茅（厚い層） | — |

## 6. 技術メモ
