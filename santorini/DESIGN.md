# 青いドームの村 Blue domes — 設計 v0.1（2026-11-10）

目的：**カルデラの崖にしがみつく白い村と、青いドームの教会、その下に広がる深い青のエーゲ海**を、手のひらサイズのジオラマにする。手本はギリシャ・サントリーニ島の **イア（Oia）** の、絵はがきでよく知られた眺め。
方針：**青と白が主役**（ユーザー「青系が伸びる」）。ラグーンの「透きとおった緑」とは別の、**濃い青と白**。形は Tiny Worlds の決まりどおり、**丸く、ずんぐり、おもちゃのように**。
進め方：**設計（この文書）→ 試作（`santorini/index.html`）→ 確認 → 仕上げ・動画・トップページ**。

## 1. 景色の分解（イアの絵はがきに見えるもの）

### 1.1 構図（絵はがきの角度）
- 縦長。**村の上の段のテラスから、斜め下を見おろす**。手前に**青いドームが3つ**重なり、その向こうに**白い家が段々に崖を下り**、奥は**一面の深い青の海**と、水平線近くに**黒い火山島**
- 画面の縦の割合：**上 1/4 が空、1/4 が海、下 1/2 が村**
- **右の尾根に風車**。白い胴に、わらぶきの帽子と羽根
- 鐘楼（白い壁に、鐘が2〜3個ぶら下がるアーチ）が、ドームのすぐ横に立つ

### 1.2 空
- 高い所は**濃い青**、水平線に向かって**白っぽい水色**。小さな白い雲が少し
- 太陽は高め、左前から。白い壁の日なたはまぶしく、影は青みの灰

### 1.3 崖（カルデラの断崖）
| 部分 | 見えるもの |
|---|---|
| 形 | 海から**ほぼ垂直に近い急斜面**で立ち上がる。上の縁に村がのる。縁は弓なりに湾をかこむ |
| 地層 | **横じまの地層**：赤茶（`#a8553a`）、黒っぽい灰（`#4d4744`）、ベージュ（`#d8c3a0`）、さび色の帯がくりかえす。上ほど明るく、下ほど暗い |
| 足もと | 波打ちぎわに黒い岩。小さな入り江（アムーディ湾のような）に**漁船の港と食堂**がある |
| 道 | **ジグザグの石段**が崖の上から港まで下りる。ロバが登り下りする |

### 1.4 村（白い家）
| 部分 | 見えるもの |
|---|---|
| 家 | **角の丸い白い立方体**（角砂糖）。崖の斜面に**段々に積み重なる**。屋根は平ら、または**かまぼこ形（ヴォールト）** |
| 洞窟の家 | 崖に掘った家：**アーチ形の入口**だけが白く見える |
| 窓と扉 | **青い扉・青い雨戸**。ところどころ**水色・黄・ピンクの家**もまじる |
| テラス | 白い低い壁で囲った平らな屋上。**白いパラソル、寝椅子** |
| プール | テラスの**インフィニティプール**：鮮やかなターコイズの小さな水面（青のアクセント） |
| 花 | **ブーゲンビリア**：濃いピンクの花のかたまりが白い壁に垂れる |
| 階段と路地 | 家と家の間を白い階段がつなぐ。手すりも白 |

### 1.5 教会
| 部分 | 見えるもの |
|---|---|
| 青いドーム | **こばるとブルーの丸屋根**（`#1f5fbf`）が、白い円筒（ドラム）の上にのる。てっぺんに小さな**白い十字架** |
| 鐘楼 | 白い壁に**アーチの穴が2段**、それぞれに**小さな青銅の鐘** |
| 数 | 主役の教会のドーム1つ＋近くに小さいドーム2つ（絵はがきの「3つ重なる」） |

### 1.6 海
- 崖の下は**深いコバルトブルー〜紺**（カルデラは深い）。港の浅い所だけ**明るいターコイズ**
- 水面はゆるいうねり、日の側がきらきら光る
- **火山島（ネア・カメニのような）**：海のまん中に低い黒っぽい島。こげ茶と黒、少し赤
- **白い帆の双胴船（カタマラン）**が湾をゆっくり回り、白い航跡を引く
- 港には**小さな木の漁船**（白い船体に青と赤のふち）

## 2. 可愛くする決まり

1. **角を全部丸くする**：家は角の丸い箱、ドームはぷっくり。とがっていいのは十字架と風車の羽根だけ
2. **ずんぐりさせる**：人は **2.5 頭身**（背 0.58）。家の1段は人の 2 倍くらい（高さ 1.1）
3. **村を角砂糖のように**：白はほんの少しクリーム寄り（`#f7f3ea`）、影は青みのある灰（`#b9c6d6`）で、真っ白に飛ばない
4. **遠近をうそにする**：崖は本物なら人の 200 倍以上だが、ここでは **12〜15 倍**
5. **色を減らす**：青・白・地層の赤茶・ブーゲンビリアの桃の4つが主役。黒は使わず紺とこげ茶
6. **海は宝石のように**：深い青は不透明に近く、港の浅瀬だけ透けて海底の白い石が見える。台の手前の**断面は濃い青のグラデーション**
7. **台にのせる**：世界全体が角丸の板の上

## 4. パーツの一覧

- **崖**：弓なりの壁。上の縁はゆるい凹凸、顔は急斜面。**地層の横じまはシェーダーで高さから**描き、ノイズで波打たせる（頂点を増やさずにすむ）。足もとに黒い岩
- **家**：角の丸い箱（幅・奥行・高さを少しずつ変える）、かまぼこ屋根、洞窟の家のアーチ。**崖の斜面の段に合わせて自動で並べる**（段ごとに奥へ下げる）。扉・雨戸は青い薄い板。全部まとめて1つのメッシュ
- **テラス**：屋上の低い白壁、パラソル、寝椅子、**インフィニティプール**（水面は透ける青、ふちから海へ続いて見える）
- **教会**：白いドラムの上の青いドーム（半球を少しふくらませる）、十字架、鐘楼と鐘（鐘はときどき揺れる）
- **風車**：白い円柱、わらぶきの円すいの帽子、木の羽根（回る）
- **石段**：崖の顔をジグザグに下りる白い段と手すり
- **ブーゲンビリア**：桃色の丸のかたまり（インスタンス）
- **海**：ラグーンの水（`lagoon/src/water.js`）の作りを使い、色を**深い青**に。港の浅瀬だけ透けて白い石の海底。うねり・きらめき・崖の足の泡
- **火山島**：低い黒っぽい丘（こげ茶と赤の筋）
- **船**：白い帆の双胴船、港の漁船（白・青・赤）
- **人と動物**：主役の旅行者（白いワンピース・麦わら帽子・カメラ）、テラスの2人組、港の食堂の人、ロバと引く人、屋根の上の猫、カモメ

動くもの：カタマランが湾をぐるりと回り航跡を引く／漁船がうねりで揺れる／風車の羽根が回る／鐘がときどき揺れる／ロバが石段を登り下りする／猫が屋根の上でしっぽを振る／旅行者がカメラを構える／カモメが崖のまわりを回る／水面のきらめき／小さな雲がゆっくり流れる。

## 5. 作り方

- **ページ**：`santorini/index.html`、部品は `santorini/src/`。舞台は `room/src/stage.js`、部品の合体は `fuji/src/kit.js`、人は `fuji/src/people.js` の `chibi`、海は `lagoon/src/water.js` を色と形を変えて再利用
- **メモリ**：崖・家・教会・石段・動かないものは頂点カラーで1つのメッシュにまとめる。ブーゲンビリアとカモメはインスタンス。船は形を1回作って共有。影は 2048 を1枚。描くのは1つのレンダラーだけ
- **灯り**：高い太陽（左前、白く少し暖かい）と、空の青・海の青の照り返し（半球光）。白い壁が飛ばないよう露出は控えめ、影は青みに。ブルームは水面のきらめきが光る程度
