# 海の生き物ライブラリ — 設計 v0.1

Tiny Worlds の**どの海でも使える**生き物の共通パーツ。最初の利用先は World 02（那覇）。あとで温帯の海や寒い海、水族館の世界などにも持っていけるように、生き物ごとに「すみか」と「水温」のタグを付けておく。

置き場所：`tiny-worlds/sealife/`（各世界から `../sealife/...` で読み込む）。カタログページも `sealife/index.html` に作る。

---

## 0. 決定事項（2026-10-28）

- **顔**：目だけ小さく（黒い目に光の点。ぬいぐるみのような控えめさ。群れても騒がしくない）
- **大きさ**：見やすさ優先。30cm以下は2〜3倍、1m前後は1.2倍、大型はほぼ実寸（§2 の「→」の右側の値を使う）
- **範囲**：洗い出した全部を作る。ただし順番は §4（共通のしくみ → 代表5種で形と動きを確定 → 残り全部）で、他の海用（ホホジロザメ、ザトウクジラなど）も含める

## 1. 全体のルール

### 1.1 見た目
- 空港と同じ**やわらかいローポリ**。面は少しだけ角が見える程度、色はパレット＋生き物ごとの差し色2〜3色
- 模様（縞・斑点・帯）はテクスチャではなく、**頂点の色と小さな形の重ね**で表現（遠目でも模様が読める太さ）
- **顔の描き方（要判断・§5）**：目だけ小さく描く／キャラクター風の大きな目／目なし

### 1.2 大きさ（要判断・§5）
- 人の縮尺は 1 unit ≈ 1.3m（身長1.3）
- 実際の比率どおりだと、ジンベエザメ（約10m）は約7.7、クマノミ（約10cm）は約0.08 で、小さい魚はほとんど見えない
- 案：**小さい生き物ほど大きめにする**「見やすい縮尺」（30cm以下は2〜3倍、1m前後は1.2倍、大型はほぼ実寸）

### 1.3 動きの種類（共通のしくみで動かす）
| 種類 | 中身 | 使う生き物 |
|---|---|---|
| くねり泳ぎ | 頭から尾へ横に波が伝わる。尾びれほど大きく振れる | 魚、サメ、ジンベエ、ウツボ、イルカ（イルカは縦に振る） |
| 羽ばたき | 胸びれ（翼）の付け根から先へ縦に波が伝わる | マンタ、トビエイ、アカエイ、ウミガメ（前ひれ） |
| 拍動 | かさが縮んで押し出す | クラゲ |
| 噴射 | 胴が縮んで後ろへ水を吐き、すっと進む | イカ、タコ（泳ぐとき） |
| 這う・歩く | 脚を交互に動かす | カニ、ヤドカリ、タコ（歩くとき） |
| ゆらぎ | その場で揺れる・伸び縮み | チンアナゴ、イソギンチャク、ウミウシ |

- 体の曲げは**頂点シェーダー**で行う（骨組み不要）。同じ種類はインスタンス描画でまとめ、1匹ずつ位相をずらす（群れでも軽い）

### 1.4 行動の種類
| 種類 | 中身 |
|---|---|
| 群れ | 近くの仲間に向きと速さを合わせ、ぶつからず、まとまる（ボイド）。人や大きな魚が来ると散ってまた集まる |
| 回遊 | 大きな輪や8の字を描いてゆっくり巡る |
| 定住 | 自分の「家」（イソギンチャク、岩穴、サンゴ）の近くから離れない |
| 底もの | 砂の上でじっとしている／ゆっくり這う／砂に潜る |
| 引っ込む | 近づくと巣穴に隠れ、しばらくして出てくる（チンアナゴ、ウツボ） |
| 息継ぎ | ときどき水面に上がる（ウミガメ、イルカ、ジュゴン、クジラ） |
| 見せ場 | まれに起きる出来事（ジンベエが横切る、イルカのジャンプ、魚の竜巻） |

### 1.5 タグ
- **すみか**：浅瀬（ラグーン）／サンゴ礁／砂地／岩・穴／外洋／深場
- **水温**：熱帯／温帯／寒帯
- **出会いやすさ**：いつも／ときどき／まれ（イベント）

## 4. 作る順番（案）

1. 共通のしくみ：くねり泳ぎ・羽ばたきのシェーダー、インスタンス描画、群れ（ボイド）
2. 代表を1種ずつ作って形と動きを確定：**魚（ナンヨウハギ）→ エイ（マンタ）→ サメ（ツマグロ）→ ジンベエザメ → ウミガメ**
3. 残りの魚、小さな生き物、イベント（イルカ、魚の竜巻）
4. カタログページ `sealife/index.html`（空港のカタログと同じく、1種ずつ回して確認できる）
5. 那覇の海に配置（すみかごとに）

## 5. 決めたいこと（要回答）

1. **顔の描き方**：目だけ小さく（ぬいぐるみのような控えめさ）／キャラクター風の大きな目（人と同じちび感）／目なし（シルエットだけ）
2. **大きさ**：実際の比率どおり／見やすさ優先（小さい生き物を大きめに）
3. **最初に作る範囲**：那覇で使う生き物から順に（§3）／洗い出した全部
